═══════════════════════════════════════════════════════════════

COMO RODAR LOCALMENTE (Node.js já instalado)
─────────────────────────────────────────────
Abra o terminal nesta pasta e execute:

    node server.js

Depois abra no navegador: http://localhost:3000


COMO HOSPEDAR (servidor PHP — hospedagem compartilhada)
────────────────────────────────────────────────────────
Use o arquivo proxy.php no lugar do server.js:
1. Faça upload de index.html e proxy.php para o servidor
2. Acesse via browser — funciona direto

Para VPS/servidor com Node.js:
1. Copie os arquivos (index.html, server.js, package.json)
2. Execute: node server.js
3. Aponte seu domínio para a porta 3000 (ou use nginx como proxy)


CONFIGURAÇÃO DO PAGAMENTO PIX (opcional)
─────────────────────────────────────────
Edite server.js e preencha suas credenciais EfíPay:

    const EFIPAY_CLIENT_ID     = 'seu_client_id';
    const EFIPAY_CLIENT_SECRET = 'seu_client_secret';
    const EFIPAY_CHAVE_PIX     = 'sua_chave_pix';

Depois em index.html, mude:
    const HABILITAR_PIX = false;
para:
    const HABILITAR_PIX = true;
